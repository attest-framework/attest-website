## Understanding Assertions

Attest uses a fluent API where you chain assertions. Each assertion validates a different aspect:

| Layer | Python | TypeScript | What it checks |
|-------|--------|------------|----------------|
| Schema | `.output_matches_schema({...})` | `.outputMatchesSchema({...})` | Output structure |
| Constraints | `.cost_under(0.10)`, `.latency_under(2000)` | `.costUnder(0.10)`, `.latencyUnder(2000)` | Performance metrics |
| Trace | `.tools_called_in_order([...])` | `.toolsCalledInOrder([...])` | Execution path |
| Content | `.output_contains("hello")` | `.outputContains("hello")` | Text content |
| Embedding | `.output_similar_to("greeting")` | `.outputSimilarTo("greeting")` | Semantic meaning |
| LLM Judge | `.passes_judge("Is this polite?")` | `.passesJudge("Is this polite?")` | Domain-specific eval |
| Trace Tree | `.agent_called("billing")` | `.agentCalled("billing")` | Multi-agent structure |
| Plugin | `.plugin("my-plugin", {...})` | `.plugin("my-plugin", {...})` | Custom checks |

Layers 1–4 and the trace tree are deterministic and free. Embedding and judge assertions call a provider; under `ATTEST_SIMULATION=1` they return `not_evaluated(simulation)` instead.

## Common Patterns

### Multiple Trials

`attest.evaluate(chain)` fails or skips the test on its own. To judge several runs together, collect each with `attest.inspect(chain)` and enforce only the aggregate; see [Verdicts](/sdk-guides/verdicts/).

### Adapter Integration

Use built-in adapters to build a trace from a provider response:

```python
from openai import OpenAI

from attest import AgentResult, OpenAIAdapter, expect

client = OpenAI()
adapter = OpenAIAdapter(agent_id="assistant")


def test_explains_recursion(attest):
    messages = [{"role": "user", "content": "Explain recursion"}]
    response = client.chat.completions.create(model="gpt-4.1", messages=messages)
    result = AgentResult(trace=adapter.trace_from_response(response, input_messages=messages))
    attest.evaluate(expect(result).output_contains("recursion").tokens_under(1000))
```

## Troubleshooting

**"API key not found"**

Embedding and judge assertions need a provider key. Set it as an environment variable:

```bash
export OPENAI_API_KEY="sk-..."
```

**"Assertion failed but I expected it to pass"**

Inspect the result the agent produced:

```python
print(result.trace.output)    # What the agent returned
print(result.trace.steps)     # LLM and tool calls in order
print(result.trace.metadata)  # Tokens, cost and latency
```

**"Tests call a paid model"**

Run with `ATTEST_SIMULATION=1`: deterministic layers still evaluate, and embedding and judge assertions report `not_evaluated(simulation)` without a provider call.
