## Installation

Install the `attest-ai` package and pytest. Attest 1.0.0-rc.1 is a pre-release and an unconstrained install resolves to the older stable release, so set a version floor:

```bash
uv add "attest-ai>=1.0.0rc1" pytest
```

For framework-specific adapters, install extras:

```bash
uv add "attest-ai[openai]>=1.0.0rc1"       # OpenAI adapter
uv add "attest-ai[langchain]>=1.0.0rc1"    # LangChain support
uv add "attest-ai[llamaindex]>=1.0.0rc1"   # LlamaIndex support
uv add "attest-ai[google-adk]>=1.0.0rc1"   # Google ADK support
uv add "attest-ai[otel]>=1.0.0rc1"         # OpenTelemetry support
```

## Run Tests

```bash
uv run pytest -v
```

`attest.evaluate(chain)` fails the test on a hard failure and skips it when an assertion could not be evaluated, naming the reason.

## Multiple Trials

Collect each trial with `attest.inspect(chain)`, which never fails or skips the test, and enforce only the aggregate with `attest.enforce(...)`. See [Verdicts](/sdk-guides/verdicts/).

## Using Adapters

Use built-in adapters for framework-specific trace capture (requires the `openai` extra):

```python
from openai import OpenAI

from attest import AgentResult, OpenAIAdapter, expect

client = OpenAI()
adapter = OpenAIAdapter(agent_id="assistant")


def test_explains_recursion(attest):
    messages = [{"role": "user", "content": "Explain recursion"}]
    response = client.chat.completions.create(model="gpt-4.1", messages=messages)

    trace = adapter.trace_from_response(response, input_messages=messages)
    result = AgentResult(trace=trace)

    attest.evaluate(expect(result).output_contains("recursion").tokens_under(1000))
```

## Simulation Mode

Run tests without provider calls: deterministic layers still evaluate, and embedding and judge assertions report `not_evaluated(simulation)`:

```bash
ATTEST_SIMULATION=1 uv run pytest -v
```

## Environment Variables

| Variable | Purpose |
|----------|---------|
| `OPENAI_API_KEY` | OpenAI API key for judge/embedding assertions |
| `ANTHROPIC_API_KEY` | Anthropic API key for judge assertions |
| `ATTEST_ENGINE_PATH` | Override engine binary location |
| `ATTEST_SIMULATION` | Enable simulation mode (no real LLM calls) |
| `ATTEST_JUDGE_PROVIDER` | LLM judge provider: `openai`, `anthropic`, `gemini`, `acp` |
| `ATTEST_JUDGE_MODEL` | Model for judge assertions (e.g., `gpt-4.1`) |
