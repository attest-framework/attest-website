## rec → replay → gate

A support agent refunded a customer twice after a payment timeout. Its tests stayed green, because they only checked the reply text. That incident — [INC-1042](https://github.com/attest-framework/refund-desk/issues/2) — becomes a regression test in three moves:

<div class="story-strip">
  <div class="story-step rec">
    <span class="step-glyph">● rec</span>
    <h3>Capture the incident</h3>
    <p><code>attest capture</code> runs the agent once and records its trace and every model exchange as a verified fixture — secrets removed, contracts drafted from the run.</p>
  </div>
  <div class="story-step play">
    <span class="step-glyph">▶ replay</span>
    <h3>Replay in CI</h3>
    <p>PR CI replays your agent's real code against the fixture through a local proxy. No provider keys, zero model calls, <code>$0.00</code> — and no flaky suites.</p>
  </div>
  <div class="story-step gate">
    <span class="step-glyph">✓ gate</span>
    <h3>Gate the merge</h3>
    <p>Every check ends as <span class="verdict pass">pass</span> <span class="verdict fail">fail</span> or <span class="verdict skip">not_evaluated</span> with a reason. The policy exits non-zero and the regression never merges.</p>
  </div>
</div>

## What it looks like

### Python

```python
from attest import agent, expect

@agent("weather-agent")
def weather_agent(builder, query: str) -> dict:
    # Your agent implementation: record tool calls on the builder
    builder.add_tool_call("get_weather", args={"city": "Tokyo"})
    ...

def test_weather_agent(attest):
    result = weather_agent(query="What's the weather in Tokyo?")

    chain = (
        expect(result)
        .required_tools(["get_weather"])                          # Layer 3: Free
        .output_contains("Tokyo")                                 # Layer 4: Free
        .output_similar_to("Current weather conditions in Tokyo")  # Layer 5: ≪$0.001
        .passes_judge("Provides accurate, helpful weather information")  # Layer 6: ~$0.001
    )
    attest.evaluate(chain)
```

### TypeScript

```typescript
import { agent, attestExpect } from '@attest-ai/core';
import { evaluate } from '@attest-ai/vitest';

const weatherAgent = agent('weather-agent', (builder, args) => {
  // Your agent implementation: record tool calls on the builder
  builder.addToolCall('get_weather', { args: { city: 'Tokyo' } });
  return { message: '...' };
});

test('weather agent returns weather data', async () => {
  const result = weatherAgent({ query: 'What is the weather in Tokyo?' });

  const chain = attestExpect(result)
    .requiredTools(['get_weather'])                               // Layer 3: Free
    .outputContains('Tokyo')                                      // Layer 4: Free
    .outputSimilarTo('Current weather conditions in Tokyo')       // Layer 5: ≪$0.001
    .passesJudge('Provides accurate, helpful weather information'); // Layer 6: ~$0.001

  await evaluate(chain);
});
```
