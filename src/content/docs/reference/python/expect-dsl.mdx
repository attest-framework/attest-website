Fluent assertion API for testing AI agent outputs across 8 validation layers.

## Overview

The `ExpectChain` class provides a fluent interface for chaining assertions. Each assertion returns the chain for further chaining. Build a chain with `expect(result)`, then evaluate it with the `attest` pytest fixture.

```python
from attest import expect

def test_agent(attest):
    result = agent.run("question")

    # Assertions can be chained
    chain = (
        expect(result)
        .output_contains("expected")
        .cost_under(0.05)
        .latency_under(2000)
        .passes_judge("Is correct?")
    )
    attest.evaluate(chain)
```

## Basic Usage

### Creating an Expect Chain

```python
from attest import expect

result = agent_function()
chain = expect(result)
```

`expect()` takes the `AgentResult` produced by an `@agent`-decorated function. The result carries:

- `trace` — Full execution trace
- `total_cost` — Token cost in dollars
- `total_duration_ms` — Execution time in milliseconds
- `assertion_results` — Per-assertion results after evaluation

### Evaluating a Chain

Building a chain does not run it. Pass the chain to the `attest` fixture:

| Method | Behavior |
|--------|----------|
| `attest.evaluate(chain)` | Evaluate and fail (or skip) the test according to the outcome |
| `attest.inspect(chain)` | Evaluate without enforcing the outcome; returns an `AgentResult` |
| `attest.enforce(verdict)` | Fail or skip the test from an `inspect()` result or an aggregate of trial results |

Every assertion method except `output_forbids` accepts `soft=True` (keyword-only) to record a failure without failing the test.

## Assertion Layers

Attest assertions work across 8 layers:

| Layer | Methods | What it validates |
|-------|---------|------------------|
| **1. Schema** | `output_matches_schema()`, `output_field_matches_schema()`, `tool_args_match_schema()`, `tool_result_matches_schema()` | JSON schema validation |
| **2. Constraints** | `cost_under()`, `latency_under()`, `tokens_under()`, `tokens_between()`, `step_count()`, `tool_call_count()`, `constraint()` | Performance metrics |
| **3. Trace** | `tools_called_in_order()`, `tools_called_exactly()`, `required_tools()`, `forbidden_tools()`, `no_tool_loops()`, `no_duplicate_tools()` | Execution path |
| **4. Content** | `output_contains()`, `output_not_contains()`, `output_matches_regex()`, `output_has_all_keywords()`, `output_has_any_keyword()`, `output_forbids()`, `content_contains()` | Text content |
| **5. Embedding** | `output_similar_to()` | Semantic meaning |
| **6. LLM Judge** | `passes_judge()` | Domain-specific evaluation |
| **7. Trace Tree** | `agent_called()`, `delegation_depth()`, `agent_output_contains()`, `cross_agent_data_flow()`, `follows_transitions()`, `aggregate_cost_under()`, `aggregate_tokens_under()`, `agent_ordered_before()`, `agents_overlap()`, `agent_wall_time_under()`, `ordered_agents()` | Multi-agent execution structure |
| **8. Plugin** | `plugin()`, `aggregate_latency_under()`, `all_tools_called()` | Custom plugin evaluations |

## Layer 1: Schema Validation

Validate output structure against a JSON schema.

```python
expect(result).output_matches_schema({
    "type": "object",
    "properties": {
        "name": {"type": "string"},
        "age": {"type": "number"}
    },
    "required": ["name", "age"]
})
```

Validate a single output field, or the arguments and result of a tool call:

```python
expect(result).output_field_matches_schema("name", {"type": "string"})
expect(result).tool_args_match_schema("search", {"type": "object", "required": ["query"]})
expect(result).tool_result_matches_schema("search", {"type": "array"})
```

| Method | Parameters |
|--------|------------|
| `output_matches_schema(schema)` | `schema: dict` |
| `output_field_matches_schema(field, schema)` | `field: str`, `schema: dict` |
| `tool_args_match_schema(tool_name, schema)` | `tool_name: str`, `schema: dict` |
| `tool_result_matches_schema(tool_name, schema)` | `tool_name: str`, `schema: dict` |

## Layer 2: Constraints

Check performance metrics and limits.

### Cost, Latency and Token Constraints

```python
# Cost in dollars
expect(result).cost_under(0.10)

# Latency in milliseconds
expect(result).latency_under(5000)

# Token counts
expect(result).tokens_under(500)
expect(result).tokens_between(100, 500)
```

### Step and Tool Call Counts

```python
# operator is a comparison operator such as "eq", "lte" or "gte"
expect(result).step_count("lte", 10)
expect(result).tool_call_count("eq", 3)
```

### Generic Constraint

```python
expect(result).constraint("metadata.cost_usd", "lte", 0.10)
expect(result).constraint("metadata.total_tokens", "between", min=100, max=500)
```

| Method | Signature |
|--------|-----------|
| `cost_under` | `(max_cost: float, *, soft=False)` |
| `latency_under` | `(max_ms: int, *, soft=False)` |
| `tokens_under` | `(max_tokens: int, *, soft=False)` |
| `tokens_between` | `(min_tokens: int, max_tokens: int, *, soft=False)` |
| `step_count` | `(operator: str, value: int, *, soft=False)` |
| `tool_call_count` | `(operator: str, value: int, *, soft=False)` |
| `constraint` | `(field: str, operator: str, value: float \| None = None, *, min=None, max=None, soft=False)` |

## Layer 3: Trace Content

Inspect which tools the agent called and in what order.

```python
# Tools must appear in this order
expect(result).tools_called_in_order(["lookup_order", "process_refund"])

# Exactly this sequence of tool calls
expect(result).tools_called_exactly(["lookup_order", "process_refund"])

# Every listed tool was called
expect(result).required_tools(["lookup_order", "process_refund"])

# None of the listed tools were called
expect(result).forbidden_tools(["delete_order", "cancel_refund"])

# A tool is not called more than N times
expect(result).no_tool_loops("search", max_repetitions=3)

# No tool is called twice
expect(result).no_duplicate_tools()
```

| Method | Signature |
|--------|-----------|
| `tools_called_in_order` | `(tools: list[str], *, soft=False)` |
| `tools_called_exactly` | `(tools: list[str], *, soft=False)` |
| `required_tools` | `(tools: list[str], *, soft=False)` |
| `forbidden_tools` | `(tools: list[str], *, soft=False)` |
| `no_tool_loops` | `(tool: str, max_repetitions: int = 1, *, soft=False)` |
| `no_duplicate_tools` | `(*, soft=False)` |

## Layer 4: Content Matching

Check the output text.

### Exact Content

```python
# Contains substring
expect(result).output_contains("hello")

# Does not contain
expect(result).output_not_contains("error")

# Case sensitive (matching is case-insensitive by default)
expect(result).output_contains("HELLO", case_sensitive=True)
```

### Pattern and Keyword Matching

```python
# Regex pattern
expect(result).output_matches_regex(r"^\d{4}-\d{2}-\d{2}$")  # Date format

# Contains all keywords
expect(result).output_has_all_keywords(["hello", "world"])

# Contains any keyword
expect(result).output_has_any_keyword(["yes", "correct"])

# Contains none of the forbidden terms
expect(result).output_forbids(["password", "ssn"])
```

### Other Targets

`content_contains()` runs a substring check against any target in the result:

```python
expect(result).content_contains("output.message", "refund")
```

| Method | Signature |
|--------|-----------|
| `output_contains` | `(value: str, *, case_sensitive=False, soft=False)` |
| `output_not_contains` | `(value: str, *, case_sensitive=False, soft=False)` |
| `output_matches_regex` | `(pattern: str, *, soft=False)` |
| `output_has_all_keywords` | `(keywords: list[str], *, case_sensitive=False, soft=False)` |
| `output_has_any_keyword` | `(keywords: list[str], *, case_sensitive=False, soft=False)` |
| `output_forbids` | `(terms: list[str])` |
| `content_contains` | `(target: str, value: str, *, case_sensitive=False, soft=False)` |

## Layer 5: Semantic Similarity

Check semantic meaning using embeddings.

```python
# Semantically similar to reference text
expect(result).output_similar_to(
    "This is a greeting",
    threshold=0.85
)
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `reference` | `str` | required | Reference text to compare against |
| `threshold` | `float \| str` | `0.8` | Minimum cosine similarity, or `"dynamic"` |
| `model` | `str \| None` | `None` | Embedding model override |
| `soft` | `bool` | `False` | Record failure without failing the test |

## Layer 6: LLM-as-Judge

Use an LLM to evaluate domain-specific correctness.

### Basic Judge

```python
expect(result).passes_judge("Is this response helpful?")
```

### With Threshold and Model

```python
expect(result).passes_judge(
    "Is the math correct?",
    threshold=0.9,
    model="gpt-4.1",
)
```

### Judge with Rubric

`rubric` names a rubric registered with the engine; the default is `"default"`.

```python
expect(result).passes_judge(
    "Grade this response",
    rubric="default",
    threshold=0.8,
)
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `criteria` | `str` | required | What the judge evaluates |
| `rubric` | `str` | `"default"` | Rubric name |
| `threshold` | `float \| str` | `0.8` | Minimum passing score, or `"dynamic"` |
| `model` | `str \| None` | `None` | Judge model override |
| `soft` | `bool` | `False` | Record failure without failing the test |

### Dynamic Thresholds (v0.6.0+)

Both Layer 5 (`output_similar_to`) and Layer 6 (`passes_judge`) accept `threshold="dynamic"` to use σ-based drift detection against historical baselines. Instead of comparing the score to a fixed value, the engine compares it to the rolling mean and standard deviation of previous scores for the same assertion.

```python
expect(result).output_similar_to("reference", threshold="dynamic")
expect(result).passes_judge("is polite", threshold="dynamic")
```

**When to use:**
- You don't know the right absolute threshold yet — let the baseline emerge from real usage
- You want to catch quality regressions that a static threshold would miss
- You're running continuous evaluation with enough history (≥ min-runs fallback) to establish a baseline

Only `"dynamic"` and floats (`0.0`–`1.0`) are accepted. Other string values raise `ValueError`:

```python
expect(result).passes_judge("is polite", threshold="bad")  # ValueError
```

See also the [Drift Detection guide](/guides/drift-detection/) and `AttestClient.query_drift(assertion_id, window_size=50)`, which returns a `DriftReport` for a specific assertion.

## Layer 7: Trace Tree Validation

Validate the structure of a multi-agent execution trace.

```python
# An agent was invoked
expect(result).agent_called("researcher")

# Delegation depth stays bounded
expect(result).delegation_depth(3)

# Output of a specific agent
expect(result).agent_output_contains("researcher", "findings")

# Data flows from one agent to another
expect(result).cross_agent_data_flow("researcher", "writer", "summary")

# Delegations follow the allowed transitions
expect(result).follows_transitions([("planner", "researcher"), ("researcher", "writer")])

# Aggregate budgets across all agents
expect(result).aggregate_cost_under(0.50)
expect(result).aggregate_tokens_under(5000)

# Ordering and concurrency
expect(result).agent_ordered_before("planner", "writer")
expect(result).agents_overlap("researcher", "fact_checker")
expect(result).agent_wall_time_under("researcher", 3000)
expect(result).ordered_agents([["planner"], ["researcher", "fact_checker"], ["writer"]])
```

| Method | Signature |
|--------|-----------|
| `agent_called` | `(agent_id: str, *, soft=False)` |
| `delegation_depth` | `(max_depth: int, *, soft=False)` |
| `agent_output_contains` | `(agent_id: str, value: str, *, case_sensitive=False, soft=False)` |
| `cross_agent_data_flow` | `(from_agent: str, to_agent: str, field: str, *, soft=False)` |
| `follows_transitions` | `(transitions: list[tuple[str, str]], *, soft=False)` |
| `aggregate_cost_under` | `(max_cost: float, *, soft=False)` |
| `aggregate_tokens_under` | `(max_tokens: int, *, soft=False)` |
| `agent_ordered_before` | `(agent_a: str, agent_b: str, *, soft=False)` |
| `agents_overlap` | `(agent_a: str, agent_b: str, *, soft=False)` |
| `agent_wall_time_under` | `(agent_id: str, max_ms: int, *, soft=False)` |
| `ordered_agents` | `(groups: list[list[str]], *, soft=False)` |

## Soft Failures

Every assertion except `output_forbids` accepts `soft=True`. A soft failure is recorded in the results but does not fail the test, so the remaining assertions still report.

```python
def test_agent(attest):
    result = agent_function()
    chain = (
        expect(result)
        .output_contains("hello", soft=True)  # Failure recorded, test continues
        .cost_under(0.01, soft=True)          # Failure recorded, test continues
        .passes_judge("...")                  # Hard assertion
    )
    attest.evaluate(chain)
```

Use `attest.inspect(chain)` to evaluate without enforcing the outcome, then `attest.enforce(verdict)` to apply it. This is the pattern for trial loops where only the aggregate verdict should decide the test.

## Error Messages

When an assertion fails, the `attest` fixture reports the failing assertions with diagnostics from the engine, including the assertion type, the expected condition and the actual value.

## Common Patterns

### Custom Judges

Use LLM evaluation for semantic correctness:

```python
(expect(result)
  .passes_judge(
    "Is the response grammatically correct?",
    threshold=0.8,
    model="gpt-4.1",
  ))
```

### Framework Integration

Capture traces from popular frameworks with the adapters. See the [Python Adapters Reference](/reference/python/adapters/) for the adapter classes and usage.

## Layer 8: Plugin Assertions

*Added in v0.5.1*

Chain custom plugin evaluations alongside built-in assertions.

### `plugin()`

```python
expect(result).plugin("my_plugin", {"threshold": 0.9})
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `plugin_id` | `str` | Registered plugin name |
| `config` | `dict \| None` | Plugin-specific configuration (default `None`) |

### `aggregate_latency_under()`

Assert total latency across all steps is below a threshold.

```python
expect(result).aggregate_latency_under(5000)
```

### `all_tools_called()`

Assert that every tool in the list was called at least once.

```python
expect(result).all_tools_called(["search", "summarize", "format"])
```
