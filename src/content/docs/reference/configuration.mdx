---
title: "Configuration Reference"
description: "Environment variables and runtime configuration for Attest engine, SDKs, and assertions."
---

All Attest configuration is driven by environment variables. No config files are required.

## Engine Discovery

| Variable | Purpose | Default |
|----------|---------|---------|
| `ATTEST_ENGINE_PATH` | Absolute path to engine binary — skips all discovery | unset |
| `ATTEST_ENGINE_NO_DOWNLOAD` | `1` / `true` / `yes` disables auto-download | unset (download enabled) |

The SDK resolves the engine binary in this order:

```
ATTEST_ENGINE_PATH
  → PATH lookup
  → ~/.attest/bin/ (shared cache, version-checked)
  → ../../bin/ (monorepo dev layout)
  → ./bin/ (local)
  → auto-download from GitHub Releases
  → error
```

## Engine Runtime

| Variable | Purpose | Default | Since |
|----------|---------|---------|-------|
| `ATTEST_ENGINE_TIMEOUT` | Max seconds to wait for an engine response before the SDK raises a timeout error | `30` | v0.5.1 |
| `ATTEST_SIMULATION` | Enable simulation mode — deterministic mock results, no engine process, no API calls | unset | v0.4.0 |

## Cost & Budget

| Variable | Purpose | Default | Since |
|----------|---------|---------|-------|
| `ATTEST_MAX_SOFT_FAILURES` | Maximum soft failures allowed in one engine session, counted across batches; `0` allows none. Exceeding it fails the batch. Replaces the removed `ATTEST_BUDGET_MAX_COST`, which counted soft failures, not cost. | unset (no limit) | v1.0.0-rc.1 |
| `ATTEST_MAX_JUDGE_CALLS` | Maximum judge-provider requests in one engine session. A request that cannot reserve a call is not sent and its assertion is `not_evaluated: budget_exhausted`. | unset (no limit) | v1.0.0 |
| `ATTEST_BUDGET_USD` | Maximum USD for attest-initiated model calls (layer 5 OpenAI embeddings and every judge request) in one engine session. Details and price overrides (`ATTEST_JUDGE_PRICE_IN`, `ATTEST_JUDGE_PRICE_OUT`) in [Engine configuration](/sdk-guides/configuration/). | unset (no limit) | v1.0.0 |
| `ATTEST_RATE_LIMIT_<PROVIDER>` | Judge requests per minute for `OPENAI`, `ANTHROPIC`, `GEMINI` or `ACP`; burst via `ATTEST_RATE_LIMIT_<PROVIDER>_BURST` | `60` | v1.0.0-rc.1 |

## Judge Cache

| Variable | Purpose | Default | Since |
|----------|---------|---------|-------|
| `ATTEST_JUDGE_CACHE_MAX_MB` | Maximum size in MB for the LLM judge response cache. Uses LRU eviction. Set to `0` to disable caching. | `100` | v0.5.1 |
| `ATTEST_CACHE_DIR` | Directory for all Attest caches (judge, embeddings, engine binary) | `~/.attest/cache` | v0.4.0 |

## History Store

| Variable | Purpose | Default | Since |
|----------|---------|---------|-------|
| `ATTEST_HISTORY_MAX_ROWS` | Maximum number of rows in the SQLite history store. Oldest rows are deleted when the limit is exceeded. | `10000` | v0.5.1 |
| `ATTEST_HISTORY_MAX_AGE_DAYS` | Auto-delete evaluation results older than this many days (enables pruning) | `30` when pruning is enabled | v0.5.1 |

## Continuous Evaluation

| Variable                       | Purpose                                                                                                                                                        | Default | Since  |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ------ |
| `ATTEST_CONTINUOUS_QUEUE_SIZE` | Maximum number of pending evaluations in the continuous eval queue. When full, new submissions block until space is available (backpressure).                  | `1000`  | v0.5.0 |
| `ATTEST_SAMPLE_RATE`           | Sampling rate (`0.0`–`1.0`) for continuous evaluation. Also readable via `getSampleRate()` / `get_sample_rate()`. Programmatic `config({ sampleRate })` takes precedence. | `0`     | v0.6.0 |

## LLM Providers

| Variable | Purpose | Default |
|----------|---------|---------|
| `OPENAI_API_KEY` | OpenAI API key for judge and embedding assertions | unset |
| `ANTHROPIC_API_KEY` | Anthropic API key for judge assertions | unset |
| `GOOGLE_API_KEY`, `GEMINI_API_KEY` | Google Gemini API key for judge assertions, in that order | unset |
| `ATTEST_JUDGE_API_KEY` | Judge API key; overrides the provider's standard key and is required with `ATTEST_JUDGE_BASE_URL` | unset |
| `ATTEST_JUDGE_BASE_URL` | Judge endpoint override, for example `http://localhost:11434/v1` for Ollama's OpenAI-compatible API | provider default |

Native Ollama judges are not implemented. Point `ATTEST_JUDGE_BASE_URL` at Ollama's OpenAI-compatible endpoint.

## Judge Configuration

| Variable | Purpose | Default |
|----------|---------|---------|
| `ATTEST_JUDGE_PROVIDER` | LLM provider for judge assertions: `openai`, `anthropic`, `gemini`, `acp` (local only) | `openai` |
| `ATTEST_JUDGE_MODEL` | Model name for judge assertions | `gpt-4.1` |

## Embedding Configuration

| Variable | Purpose | Default |
|----------|---------|---------|
| `ATTEST_EMBEDDING_PROVIDER` | Embedding provider: `auto`, `openai`, `onnx` | `auto` |

`auto` selects OpenAI when `OPENAI_API_KEY` is set, otherwise ONNX (free, local) in `onnx` builds.

## Example `.env`

```bash
# Engine
ATTEST_ENGINE_TIMEOUT=30
ATTEST_SIMULATION=0

# Budget
ATTEST_MAX_SOFT_FAILURES=5
ATTEST_BUDGET_USD=1.00

# Cache & history
ATTEST_JUDGE_CACHE_MAX_MB=100
ATTEST_HISTORY_MAX_ROWS=10000
ATTEST_HISTORY_MAX_AGE_DAYS=30
ATTEST_CONTINUOUS_QUEUE_SIZE=1000

# Provider keys
OPENAI_API_KEY=sk-...
ATTEST_JUDGE_PROVIDER=openai
ATTEST_JUDGE_MODEL=gpt-4.1
```
