Upgrade from PromptFoo's YAML-based testing to Attest's fluent Python/TypeScript API.

## Why Migrate?

PromptFoo is great for prompt evaluation. Attest provides:

- **Agent testing** — Not just prompts, entire agents
- **Code-first** — Python or TypeScript instead of YAML
- **Six evaluated layers plus plugins** — From schema to LLM judge
- **Framework adapters** — LangChain, CrewAI, LlamaIndex
- **Trace inspection** — See model calls, tools, costs
- **Multi-agent** — Simulation runtime for scenarios

## Concept Mapping

| PromptFoo | Attest | Notes |
|-----------|--------|-------|
| `prompts/` | Agent functions | Code instead of files |
| `test.yaml` config | Python test functions | More expressive |
| `providers` | Adapters | Built-in providers |
| `asserts` | Assertion methods | Fluent DSL |
| `eval` | Pytest + expect() | Native test framework |
| Metric | Judge prompt | LLM evaluation |

## Step-by-Step Migration

### 1. Replace YAML Config with Python Tests

#### PromptFoo (YAML)

```yaml
# promptfooconfig.yaml
providers:
  - id: openai:gpt-4o-mini
    config:
      temperature: 0.7

prompts:
  - id: simple_qa
    raw: "Answer this question: {{question}}"

tests:
  - vars:
      question: "What is 2+2?"
    assert:
      - type: contains
        value: "4"
      - type: regex
        value: "^\\d+$"
      - type: cost
        threshold: 0.01
```

#### Attest (Python)

```python
from openai import OpenAI

from attest import AgentResult, OpenAIAdapter, expect

client = OpenAI()  # reads OPENAI_API_KEY
adapter = OpenAIAdapter(agent_id="qa")

def test_simple_qa(attest):
    """Test simple Q&A."""
    messages = [{"role": "user", "content": "Answer: What is 2+2?"}]
    response = client.chat.completions.create(model="gpt-4.1", messages=messages)

    trace = adapter.trace_from_response(response, input_messages=messages, cost_usd=0.002)
    result = AgentResult(trace=trace)

    chain = (
        expect(result)
        .output_contains("4")
        .output_matches_regex(r"^\d+$")
        .cost_under(0.01)
    )
    attest.evaluate(chain)
```

### 2. Convert PromptFoo Providers to Adapters

#### PromptFoo

```yaml
providers:
  - id: openai:gpt-4o-mini
  - id: anthropic:claude-3-sonnet
  - id: localai:mistral
```

#### Attest

```python
from attest import AnthropicAdapter, OllamaAdapter, OpenAIAdapter

# Each provider adapter converts that provider's response into a Trace
openai_adapter = OpenAIAdapter(agent_id="openai-agent")
anthropic_adapter = AnthropicAdapter(agent_id="anthropic-agent")
ollama_adapter = OllamaAdapter(agent_id="local-agent")

trace = openai_adapter.trace_from_response(response, input_messages=messages)
```

### 3. Convert PromptFoo Asserts to Expect

#### PromptFoo Asserts

```yaml
assert:
  - type: contains
    value: "success"
  - type: regex
    value: '^\d{4}-\d{2}-\d{2}$'
  - type: length
    value: 100
    threshold: 0.1
  - type: cost
    threshold: 0.05
  - type: json-path
    value: "$.status"
```

#### Attest Expects

```python
chain = (
    expect(result)
    .output_contains("success")
    .output_matches_regex(r'^\d{4}-\d{2}-\d{2}$')
    .cost_under(0.05)
    .output_field_matches_schema("status", {"type": "string"})
)
attest.evaluate(chain)
```

### 4. Convert Test Variables to Test Functions

#### PromptFoo

```yaml
tests:
  - description: "Math question"
    vars:
      question: "What is 2+2?"
      topic: "math"
    assert:
      - type: contains
        value: "4"
  - description: "History question"
    vars:
      question: "When was WWII?"
      topic: "history"
    assert:
      - type: contains
        value: "1939"
```

#### Attest

```python
import pytest

@pytest.mark.parametrize("question,expected", [
    ("What is 2+2?", "4"),
    ("When was WWII?", "1939")
])
def test_qa(attest, question, expected):
    """Test Q&A across topics."""
    result = agent.run(question)
    attest.evaluate(expect(result).output_contains(expected))
```

### 5. Replace Metric Scripts with Judge Prompts

#### PromptFoo

```yaml
tests:
  - vars:
      query: "Is this helpful?"
    assert:
      - type: script
        value: "result.output.length > 100"
      - type: script
        value: |
          const score = result.output.includes('yes') ? 1 : 0;
          return { pass: score > 0.5 };
```

#### Attest

```python
def test_helpful_response(attest):
    result = agent.run("question")

    chain = (
        expect(result)
        .output_matches_regex(r"(?s).{100,}")  # at least 100 characters
        .passes_judge(
            "Is this response helpful?",
            threshold=0.8,
            model="gpt-4.1",
        )
    )
    attest.evaluate(chain)
```

## Complete Migration Example

### Before: PromptFoo Setup

```yaml
# promptfooconfig.yaml
providers:
  - id: openai:gpt-4o-mini

prompts:
  - id: qa_agent
    raw: |
      You are a helpful assistant.
      Answer this question: {{query}}

tests:
  - description: "Math question"
    vars:
      query: "What is 2+2?"
    assert:
      - type: contains
        value: "4"
      - type: regex
        value: '^4$'
      - type: cost
        threshold: 0.01

  - description: "History question"
    vars:
      query: "What year did WWII end?"
    assert:
      - type: contains
        value: "1945"
      - type: cost
        threshold: 0.02

  - description: "Response quality"
    vars:
      query: "Tell me about Python"
    assert:
      - type: length
        threshold: 0.5
        value: 200
      - type: javascript
        value: |
          const words = result.output.split(' ').length;
          return { pass: words > 50, score: Math.min(words / 100, 1) };
```

Run with:

```bash
promptfoo eval
```

### After: Attest Setup

```python
# test_agent.py
import pytest
from attest import expect

class TestAgent:
    @pytest.fixture
    def agent(self):
        from my_app import create_agent
        return create_agent()

    def test_math_question(self, attest, agent):
        """Math question should return correct answer."""
        result = agent.run("What is 2+2?")

        attest.evaluate(
            expect(result)
            .output_contains("4")
            .output_matches_regex("^4$")
            .cost_under(0.01)
        )

    def test_history_question(self, attest, agent):
        """History question should return correct year."""
        result = agent.run("What year did WWII end?")

        attest.evaluate(
            expect(result)
            .output_contains("1945")
            .cost_under(0.02)
        )

    def test_response_quality(self, attest, agent):
        """Response should be comprehensive."""
        result = agent.run("Tell me about Python")

        attest.evaluate(
            expect(result)
            .output_matches_regex(r"(?s).{500,}")
            .passes_judge("Is this well-written and informative?")
        )
```

Run with:

```bash
uv run pytest test_agent.py -v
```

## PromptFoo to Attest Feature Map

| PromptFoo Feature | Attest Equivalent |
|-------------------|-------------------|
| Web UI evaluation | Python/TS code + pytest |
| YAML config | Python test functions |
| Multiple prompts | Multiple test functions |
| Provider selection | Adapter selection |
| Contains assert | `.output_contains()` |
| Regex assert | `.output_matches_regex()` |
| Cost tracking | `.cost_under()` |
| Custom JS eval | `.passes_judge()` |
| CSV test data | pytest parametrize |
| Batch evaluation | pytest + parameterize |

## Key Differences

### 1. Code Over Config

PromptFoo uses YAML, Attest uses Python/TypeScript. More expressive and testable:

```python
# Attest: can use variables, loops, logic
for query in queries:
    result = agent.run(query)
    attest.evaluate(expect(result).output_contains("..."))
```

### 2. Agents Over Prompts

Test entire agents, not just prompts:

```python
from attest import AgentResult, LangChainAdapter, expect

# Full LangChain agent with tools
adapter = LangChainAdapter(agent_id="research-agent")

with adapter.capture() as handler:
    agent.invoke({"input": "..."}, config={"callbacks": [handler]})

result = AgentResult(trace=adapter.trace)
attest.evaluate(expect(result).required_tools(["google_search"]))
```

### 3. Fluent API Over Assertions List

Chain assertions naturally:

```python
# Attest: fluent, readable
chain = (
    expect(result)
    .output_contains("answer")
    .cost_under(0.05)
    .passes_judge("Is correct?")
)
attest.evaluate(chain)
```

## FAQ

**Can I run PromptFoo and Attest in parallel?**

Yes, during migration. But consolidate to Attest once complete.

**How do I evaluate multiple prompts like PromptFoo?**

Use test parametrization:

```python
@pytest.mark.parametrize("prompt,expected", [
    ("Prompt A", "Expected A"),
    ("Prompt B", "Expected B")
])
def test_prompts(attest, prompt, expected):
    result = agent.run(prompt)
    attest.evaluate(expect(result).output_contains(expected))
```

**How do I replace PromptFoo's batch mode?**

pytest automatically runs all test functions:

```bash
uv run pytest test_agent.py  # Runs all tests
```

**What about PromptFoo's web UI?**

Attest is code-first. Use IDE + test output for feedback. No UI needed.
